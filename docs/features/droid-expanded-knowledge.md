# Feature: M4-ND conversation and gameplay encyclopedia
Status: playable
Branch: bilal/droid-expanded-knowledge

## Player experience
Players can greet or thank M4-ND, discuss Star Wars and relevant Minecraft mechanics, and ask detailed questions about MandoMC materials, mobs, recipes, equipment and systems. A short follow-up retains the same player's topic for five minutes. Greetings and direct live balance/event answers spend no AI allowance. Other generated replies use the existing limits and private chat delivery.

## Rules
MandoMC mechanics require verified release facts. Star Wars canon/Legends and general model knowledge never establish server mechanics. Spawn rules describe eligibility rather than a creature's live location. Health uses hit points; base damage and scripted attack damage remain distinct. No actions are performed. Personal data never enters repository indexing or the AI; only the requesting player's own balance is read directly from the existing ledger. Event answers use the existing event manager. Conversations expire and clear on disconnect/restart. Safe interaction/combat/tutorial rules remain authoritative.

## Smallest playable version
Ask "hi", "Who is Darth Vader?", "Where do Massiffs spawn?", "How much health do they have?", "Where can I find durastel?", "What is my balance?", and "What event is next?". Verify each follows the appropriate conversation, lore, exact-source or live response path.

## Ownership and integrations
The guide owns conversation context and read-only knowledge retrieval. Credits and event scheduling retain their existing authorities. Groq receives only the question, optional previous topic and bounded selected public facts. Builds bundle every approved source with hashes and the exact source identity; public repository retrieval remains a same-version fallback.

## Parameters
The paired protocol-droid configuration defines conversation phrases/replies, live response text and the existing budgets. AI reservation is 6000 tokens. Context holds at most 256 recent players for five minutes. Four structured records and three source passages are candidates; model evidence is capped at 9000 characters. Changes activate through a normal restart.

## Verification
Automated checks cover routing, lore/server separation, context isolation/expiry, exact sources and overrides, material typos/acquisition links, health units, spawn eligibility, scripted damage, crate weight arithmetic, offline bundle loading, and release freshness/tamper/coverage failures. The probability assertion accepts equivalent decimal percentages and Unicode spacing. Development deployment follows the normal stopped, backed-up workflow.
